# Checkers (1.0.321)

The board has a wood background, raised tokens, icon controls and a fixed-height turn label. Human turns say “Your turn”; computer turns use Ben, Joe, Sophia, Lisa or Alpha. In nearby play each device calls its own player “Your turn” and the remote player “Alpha”. Turn changes update the label without rebuilding or moving the board. All Checkers interface text is English.

A solo win awards Ben/Beginner 1, Joe/Easy 2, Sophia/Medium 3, Lisa/Hard 4 or Alpha/Expert 5 stars. Persistent match IDs prevent duplicate rewards after recreation or resuming a finished match. Losses and draws award no stars. Board and token catalogs contain native visual previews; existing designs remain unlocked.

Daily Tournament is an offline, device-local five-round ladder, one entry per local calendar date. It advances from Ben to Alpha. A draw repeats the current round, a loss ends that day's entry, losing the final records second place, and winning the final records a tournament win. Each won round earns that opponent's usual stars (15 for all five wins). Progress survives restarting the app. This is not an online leaderboard or synchronized tournament service.

Stats displays separate solo, tournament and nearby tables. Each table can be reset after confirmation; earned stars, match reward records and the current daily entry are retained.
